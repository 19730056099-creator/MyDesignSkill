# NEEDMATERIAL.md — 速通期末所需关键信息清单

> 使用场景：用户提出「速通 / 速成期末」类请求时，按本清单快速收集信息。
> 原则：时间极紧时不要用大量澄清问题拖延，先声明假设、直接开工；本清单用于正常情况下的信息收集。

## 1. 考试约束

- **剩余时间**：距离考试还有几天？每天能投入几小时？
- **考试范围**：上册还是下册？学到哪一章？（例：极限 / 导数 / 积分 / 级数 / 多元微分…）
- **开闭卷规则**：开卷 / 闭卷 / 一页纸？
- **目标分数**：及格即可，还是冲 85+？

## 2. 题型与分值

- 选择 / 填空 / 计算 / 证明 / 应用题各占多少分？

## 3. 资料盘点（有则提供文件，无则说明）

- [ ] 老师复习课 PPT / 课堂上划的重点
- [ ] 往年题 / 期中卷
- [ ] 作业题集
- [ ] 指定教材版本（如同济版高数）
- [ ] 个人笔记 / 错题本

## 4. 用户状态

- 自我感觉最薄弱的章节是哪几个？
- 已复习到什么程度？
- 平时作业/测验中反复出错的类型？

---

## 紧急模式例外

若用户出现「明天考试」「今晚速成」「还有 30 分钟」「别问了，直接开搞」等信号：

1. 不进行上述宽泛访谈；
2. 用现有资料判断题型和优先级；
3. 直接输出「必须拿下 / 值得尝试 / 果断放弃」三级清单；
4. 给出计算题流程或主观题采分骨架；
5. 对不确定内容标注证据等级，之后再根据用户试卷微调。
